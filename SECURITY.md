# Security policy

This repository is a public reference implementation built with synthetic data.
Do not submit employer information, credentials, personal data, model secrets, or
production endpoints in issues, examples, or pull requests.

Report a suspected vulnerability privately to
[abhi07gupta@gmail.com](mailto:abhi07gupta@gmail.com). Include the affected
version, reproduction steps, impact, and any suggested mitigation. Please do not
open a public issue until a fix is available.
