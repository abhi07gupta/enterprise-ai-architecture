# Enterprise AI Decision Canvas

The canvas makes a proposed AI initiative reviewable before architecture detail
creates false certainty. It treats value, operating context, system boundaries,
trust, run ownership, and adoption as one decision system.

## Review sequence

1. State the outcome and baseline before selecting technology.
2. Describe the user workflow and the boundary the AI must not cross.
3. Make failure recoverable through fallback and human authority.
4. Name the service owner, monitoring signals, and incident path.
5. Define how people will learn, challenge, and improve the capability.

The generated score is a conversation aid, not an approval. High scores do not
override legal, security, privacy, safety, architecture, or business ownership.
