# Enterprise AI decision framework

## Sequence

**Outcome → Suitability → Context → Reasoning → Integration → Trust → Evaluation → Operations → Adoption**

### Outcome
- Which decision or workflow changes?
- What would success look like without referencing a model metric?

### Suitability
- Can rules, workflow redesign or classical software solve the problem more reliably?
- Is uncertainty acceptable in the target decision?

### Context
- Which facts, relationships, terminology and policies are required?
- What provenance must remain visible?

### Reasoning
- What is the simplest approach that meets the need?
- Which parts require deterministic behavior?

### Integration
- Where are the service boundaries?
- Which systems remain systems of record?

### Trust
- What are the material failure modes?
- Where does human review remain mandatory?

### Evaluation
- Which offline metrics correlate with real usefulness?
- What business or user evidence validates deployment?

### Operations
- Who owns runtime quality, cost, incidents and change?
- How can a model/service be replaced without redesigning the full system?

### Adoption
- How does the capability fit existing work?
- What behavior or process must change for value to appear?
