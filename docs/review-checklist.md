# Architecture review checklist

- [ ] The business owner accepts the outcome and counter-metrics.
- [ ] The baseline is observable and the success measure is time-bound.
- [ ] Data classification and permitted use are explicit.
- [ ] The model or agent cannot silently expand its authority.
- [ ] Evaluations cover quality, failure, bias, misuse, cost, and latency.
- [ ] Human review is positioned at the consequence boundary.
- [ ] A degraded mode and rollback path exist.
- [ ] Run ownership, monitoring, and incident response are funded.
- [ ] Adoption work is owned and feedback can change the design.
- [ ] The decision record explains alternatives and residual risk.
